Pulse Factory 모델 관리 프로젝트

Unity 6000.3.24f1 / Universal Render Pipeline
Asset_Showcase.unity: 가져온 모델을 한눈에 확인하는 장면

각 모델 폴더에는 FBX, 통합 PNG 텍스처 한 장, 머티리얼, 프리팹이 있습니다.
최종 모델: 연구 공장, 증폭 공장, 축전 공장, 코어, 하이퍼루프 입구, 하이퍼루프 통로.
파워보드는 요청에 따라 FBX와 애니메이션 없이 정적 이미지 한 장과 표시용 머티리얼로 제공됩니다.
전시 장면의 바닥은 이 이미지를 적용한 Unity 기본 Plane입니다.

전체 모델 루트의 원점은 바닥 중앙입니다. 각 부품의 애니메이션 축은 유지했습니다.
원점은 Unity Renderer bounds 기준으로도 확인했습니다. Validation.txt에 결과가 있습니다.
원본 Blender 파일은 수정하지 않았으며, 정리본과 FBX는 E:/blender/Unity_Ready에 있습니다.

FBX는 Apply Transform과 단위 스케일 적용을 켜고, 부모 계층의 움직임을 월드 좌표로 베이크하여 내보냈습니다. 모델이 똑바로 선 상태에서 루트 회전 0, 스케일 1입니다.
PulseModelPlayback이 FBX 클립을 반복 재생합니다. 코어 반짝임, 연구·축전 충전, 증폭 전류는 Unity용 미리보기 셰이더와 스크립트로 재구성했습니다. 파워보드는 정적입니다.
Blender 셰이더의 자동 변환본이 아닌 시각적 재현이며, 실제 게임의 전력 수치나 이벤트에는 아직 연결하지 않았습니다.
통합 프리팹은 연구·증폭·축전 공장 및 코어 각각 머티리얼 1개, 하이퍼루프 입구·통로 각각 불투명/투명 머티리얼 2개를 사용합니다. 파워보드는 정적 머티리얼 1개입니다.
통합에 필요한 부품별 금속성, 매끄러움, 발광, 충전 구분은 UnifiedMeshes의 UV 채널과 정점 색상에 저장합니다. UnifiedModel 셰이더가 이를 읽습니다.
재사용할 때는 모델 폴더의 .prefab을 장면에 넣으십시오. 원본 FBX를 직접 배치하면 통합 메시와 재생 설정이 포함되지 않습니다. 다른 프로젝트로 옮길 때는 프리팹의 종속 에셋과 공통 셰이더 및 PulseModelPlayback을 함께 옮겨야 합니다.
FBX와 PNG는 같은 모델 폴더에서 함께 보관하고, 이동할 때는 Unity Project 창을 사용해 참조를 유지하십시오.
