---
name: unity-scene-validation
description: Validate loaded scenes for missing scripts and reference contracts.
---

Confirm the intended Editor and use Codex Harness/Validate Open Scenes. It checks inactive children, Missing Script slots, broken references and required None fields marked with Odin Required. Optional None is valid. Unopened scenes/prefabs and managed-reference graphs are outside coverage. Do not mass-edit YAML or invent contracts.
